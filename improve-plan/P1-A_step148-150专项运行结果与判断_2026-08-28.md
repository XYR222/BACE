## 6. 当前判断

### 已确认

1. step148 断点恢复链路可用，global step、optimizer、dataloader 和 BACE history 能够连续恢复。
2. Rmin=2→4 的受控迁移能够被识别并执行，未发生参数不匹配或静默重置。
3. Exact Batch-ERV、packed root、selected-worker、active compaction 和 Replay trace 链路均正常。
4. micro/logprob `16/16` 在 4×H100 上完成本次流程，解决了此前 `32/32` 的 PPO backward OOM 风险。
5. checkpoint 保存和跨实验安全轮转修复在本次作业中没有删除源 checkpoint，也没有混用 A/C 输出。

### 尚不能由本次运行确认

1. 这不是 0→150 的完整重新训练，不能据此判断最终模型质量或学习曲线。
2. 只观察了 step149–150，不能充分估计不同训练阶段的 quota 修正率、Replay 时间和显存峰值。
3. C 的较低修正率和 root 生成时间优势目前是小样本现象，需要更长稳定性作业或正式训练验证。
4. validation success rate `0.875` 只能作为本次断点附近的检查结果，不应解释为完整实验最终准确率。
