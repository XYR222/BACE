## 2. 启动时的环境准备

每个 C0--C8 脚本会自行执行下列步骤；手工调试时应使用同一顺序：

```bash
module purge
module load GCCcore/13.3.0
module load CUDA/12.8.0

source /home/xsz96350/miniforge3/etc/profile.d/conda.sh
conda activate /hpcwork/xsz96350/fu_project/verl-agent

# 当前 vLLM 与 H100 组合不强制指定 attention backend。

export ALFWORLD_DATA=/home/xsz96350/.cache/alfworld
export HF_DATASETS_OFFLINE=1 HF_HUB_OFFLINE=1
export PYTHONNOUSERSITE=1 TOKENIZERS_PARALLELISM=false
```

训练脚本还会限制 OpenMP/BLAS/Rayon 线程，并给每个 Slurm job 创建独立的 `/tmp/bace_ray_<user>_<jobid>` Ray 临时目录。不要在多个作业间手工共享 Ray head 或 `RAY_TMPDIR`。

## 3. 从零重建的推荐顺序

以下是重建等价环境的起点。必须在 GPU 节点以 `nvidia-smi`、`python -c 'import torch; ...'` 和 1-step smoke 验证后，才可用于正式训练。

```bash
module purge
module load GCCcore/13.3.0
module load CUDA/12.8.0

source /home/<user>/miniforge3/etc/profile.d/conda.sh
conda create -p /hpcwork/<account>/<user>/verl-agent python=3.12 -y
conda activate /hpcwork/<account>/<user>/verl-agent

# 与当前训练环境对齐的核心二进制包。
pip install vllm==0.11.0
pip install flash-attn==2.7.4.post1 --no-build-isolation --no-cache-dir

cd <workspace>/work-BACE/verl-agent-src
pip install -e .

# ALFWorld 运行时依赖。
pip install gymnasium==0.29.1 stable-baselines3==2.6.0 alfworld==0.4.2 pytest
```

上面的安装命令来自仓库 README 并补充了当前 ALFWorld/测试版本；它不是对 CUDA 扩展 wheel 的字节级锁定。新环境实际解析到的 torch、xformers 和 flash-attn build tag 必须与“当前已验证的环境”部分逐项比较。若无法对齐，应在独立 prefix 中排障，**不要改动现有 `/hpcwork/xsz96350/fu_project/verl-agent` 环境**。

安装后只应安装仓库本体并做一致性检查：

```bash
cd <workspace>/work-BACE/verl-agent-src
pip install -e .
python -m pip check
```

不要在已验证 prefix 中执行 `pip install -r requirements.txt`：该文件是开发范围依赖，当前仍钉住 `transformers==4.51.1`，而 vLLM 0.11.0 要求 `transformers>=4.55.2`，实际已验证环境为 `transformers==4.57.3`。如确有开发依赖需求，应在独立 prefix 中安装并重新进行 GPU smoke。

## 5. GPU 节点上的最小验证

在 Slurm 分配到 H100 后运行：

```bash
nvidia-smi -L
python - <<'PY'
import torch, vllm
print('torch=', torch.__version__)
print('cuda=', torch.version.cuda)
print('available=', torch.cuda.is_available(), 'count=', torch.cuda.device_count())
print('vllm=', vllm.__version__)
PY
```

对 C0--C8 当前正式入口，必须看到两张 GPU，随后先执行交接说明中的 `DRY_RUN=1` 与 1-step smoke。只有出现 `training/global_step:1`、退出码 0 且 trace validation `ok=true`，才可提交 150-step 正式训练。
